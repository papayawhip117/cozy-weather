# 🌿 cozy weather

A simple desktop weather app

This project started as a practice project while learning **JavaScript**, and was also my first time working with **Electron, Homebrew, and Node.js**.

### ☁️ What it does

* Displays current weather
* Shows today's high and low
* Changes the weather description and icon based on current conditions
* Includes a time-based greeting
* Uses the Open-Meteo API for weather data

### 🌱 About

This is an ongoing project that I'll continue building and experimenting with as I learn more.

For now, it's mostly a space to practice **JavaScript, Electron, APIs, and building desktop apps** while making something fun.

More to come ♡
